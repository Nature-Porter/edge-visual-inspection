# Dataset provenance and split contract

The project uses the official [MVTec AD `metal_nut` category](https://www.mvtec.com/research-teaching/datasets/mvtec-ad/downloads) for noncommercial research. Commercial use requires separate data rights. Images, masks and auxiliary archives remain outside Git.

The official `metal_nut.tar.xz` was placed at `data/raw/metal_nut.tar.xz` and unpacked to `data/raw/metal_nut`. The archive SHA256 in `reports/downloads.json` is `86e3c8e163ceb19146ad3ddc408e85cc34ae02e0da430e07a73bac6bbb48532a`. Each image and mask hash is fixed in the generated split JSON files; `tools/prepare_data.py` refuses duplicate bytes and invalid/missing masks. The split algorithm uses seed 42, a 70%/15%/remainder partition of official normal training images, and stratified round-half-up 30% of each official test defect type for development validation. Counts and exact split hashes are in `reports/data_protocol.json`.

`train_normal` trains the student and autoencoder. `stats_normal` provides teacher channel statistics and normal anomaly-map quantiles. `calibration` samples at most 128 images from `train_normal`, an intentional overlap recorded in JSON. `validation` is used for model/threshold/quantization selection. `test` remains unread by P1–P6 quality tools and requires a frozen candidate in P7. `data/replay.json` contains development validation images only. Repeated replay frames do not increase quality sample counts.

Anomalib 2.1.0 teacher weights came from its [official release](https://github.com/open-edge-platform/anomalib/releases/tag/efficientad_pretrained_weights); archive SHA256 is `c09aeaa2b33f244b3261a5efdaeae8f8284a949470a4c5a526c61275fe62684a`. [Imagenette2](https://s3.amazonaws.com/fast-ai-imageclas/imagenette2.tgz) archive SHA256 is `6cbfac238434d89fe99e651496f0812ebc7a10fa62bd42d6874042bf01de4efd`, verified in `reports/imagenette-verified.json`. `tools/train.py` checks both local directories before calling any Anomalib resource preparation hook so that project commands never initiate resource downloads.
